# MECHWORLD

Professional, responsive mechanical-engineering website built with plain HTML, CSS and JavaScript.

## Open in VS Code
1. Extract the `MECHWORLD.zip` folder.
2. In VS Code, choose **File → Open Folder...** and select the `MECHWORLD` folder.
3. Open `index.html` in your browser, or use the Live Server extension if installed.

## Files
- `index.html` — page structure
- `css/style.css` — styling and responsive layouts
- `js/script.js` — mobile navigation, theme toggle, interactive calculators, contact email draft
- `images/` — place your own images here if you want to use local assets

## Notes
- Google Fonts and the hero photo use internet URLs.
- The contact form opens the visitor's email app; it does not send or store messages on its own.
- Calculators are educational helpers; verify results and assumptions before engineering use.
